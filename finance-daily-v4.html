FINANCE DAILY — an experimental, self-updating news & markets front page. V4.
Every figure and headline on this page comes from data.json, a file a scheduled Python job (fetch_data.py, run by GitHub Actions every 30 minutes) writes and commits to this repo. Indices and watchlist quotes use yfinance; crypto uses CoinGecko; FX uses open.er-api.com; headlines are pulled from public RSS feeds. None of these calls happen in your browser, so there are no API keys to protect and no per-visitor rate limits. Market Movers are computed only from your watchlist, not the full market. Informational only — not financial advice.
